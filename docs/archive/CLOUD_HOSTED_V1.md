# Retired hosted architecture (historical only)

The first design considered a private hosted job, cloud scheduler, object-storage leases and
snapshots, and a paid language-model API. It was retired before production activation because
the project has a strict zero-platform-cost requirement and must not charge a borrowed account.

This note is intentionally non-executable. It contains no deployment commands, infrastructure
configuration, credentials, secret names, or active workflow. The supported runtime is the
local Windows architecture documented in the repository root and operations guide.
